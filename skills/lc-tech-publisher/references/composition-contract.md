# HyperFrames Composition Contract (for this skill)

A condensed reference for the HTML compositions this skill generates. Full upstream docs: `npx --yes hyperframes docs` or the hyperframes-core skill.

## 1. Project Shape

```text
dist/
├── cover/
│   ├── cover.html          # entry point for the cover render
│   └── logos/lc.svg        # brand mark
└── video/
    ├── index.html          # entry point for the video render
    ├── hyperframes.json    # project config (see below)
    └── audio/scene-NN.wav  # per-scene narration clips
```

`hyperframes.json` (minimal):

```json
{
  "$schema": "https://hyperframes.heygen.com/schema/hyperframes.json",
  "paths": { "assets": "assets" }
}
```

## 2. Composition Rules

- The root element carries `data-composition-id`, `data-start`, `data-duration`, `data-width`, `data-height`.
- Timed visual elements carry `class="clip"`, `data-start`, `data-duration`, and `data-track-index`.
- Use CSS `z-index` for visual layering; `data-track-index` is only for timing conflicts.
- Audio is standalone `<audio class="clip">` elements with `data-start`, `data-duration`, `data-track-index`, `src`, and `data-volume`.
- Captions are `<div class="cap clip">` with the same timing trio.

### Master skeleton (generated by `build-composition.mjs`)

```html
<!doctype html>
<html lang="zh">
  <head>
    <meta charset="UTF-8" />
    <script src="https://cdn.jsdelivr.net/npm/gsap@3.14.2/dist/gsap.min.js"></script>
    <style> /* brand tokens from references/brand-design.md */ </style>
  </head>
  <body>
    <div
      id="master-root"
      data-composition-id="master"
      data-width="1920"
      data-height="1080"
      data-start="0"
      data-duration="<TOTAL>"
    >
      <!-- one .scene.clip per scene -->
      <div class="scene clip" data-start="<S>" data-duration="<D>" data-track-index="1">
        <div class="scene-eyebrow">01 · KEYWORD</div>
        <h1 class="scene-title">Scene headline</h1>
        <ul>
          <li class="scene-bullet">bullet</li>
        </ul>
        <pre class="scene-code"><code>…</code></pre>
      </div>
    </div>

    <!-- captions: body-level siblings -->
    <div class="cap clip" data-start="<S>" data-duration="<D>" data-track-index="10">narration text</div>

    <!-- audio: body-level siblings -->
    <audio class="clip" src="audio/scene-01.wav" data-start="<S>" data-duration="<D>" data-track-index="20" data-volume="1"></audio>

    <script>
      window.__timelines = window.__timelines || {};
      var tl = gsap.timeline({ paused: true });
      // absolute entrance animations per scene, aligned to timestamps.json
      // (see references/motion-audio.md)
      window.__timelines["master"] = tl;
    </script>
  </body>
</html>
```

## 3. Timing Attributes

| Attribute | Meaning | Required |
|-----------|---------|----------|
| `data-composition-id` | Unique composition id | root only |
| `data-width` / `data-height` | 1920 / 1080 | root |
| `data-start` | Timeline second this clip begins | every clip |
| `data-duration` | Clip length in seconds | every clip |
| `data-track-index` | Ordering for simultaneous clips | every clip |
| `data-volume` | 0–1 audio gain | audio |
| `data-composition-src` | Sub-composition path | sub-comps only |

## 4. Validation & Render Commands

```bash
cd dist/video
npx --yes hyperframes lint              # structural checks
npx --yes hyperframes check             # lint + browser audit (contrast, layout, motion)
npx --yes hyperframes snapshot --at 1,5 # smoke-test frames
npx --yes hyperframes render --quality draft   # fast iteration render
npx --yes hyperframes render --quality standard # delivery render
```

The render is deterministic: identical HTML input always produces identical MP4 output.

## 5. Common Pitfalls

- `data-duration` on scenes must match the real audio duration — a mismatch causes the scene to cut mid-word.
- `<audio>` clips must be body-level siblings of the stage, not nested inside the composition root.
- Do not animate layout properties; only `transform` and `opacity`.
- Keep all media local under the project dir; CDN fonts/images at render time are fragile.
- `hyperframes validate` / `inspect` are deprecated aliases of `check` — use `check`.
